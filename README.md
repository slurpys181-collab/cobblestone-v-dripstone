# Cobblestone V Dripstone

A Minecraft Bedrock behavior pack for Bedrock 26.52 that lets you craft one pointed dripstone using three cobblestone in a V shape.

## Recipe

Use a crafting table. Put cobblestone in the top-left, top-right, and bottom-centre slots to make 1 pointed dripstone.

## Download

Download the [Cobblestone V Dripstone MCPACK](./Cobblestone-V-Dripstone.mcpack), then open it to import into Minecraft Bedrock. Enable it under your world's Behavior Packs.

## Website

The repository includes `index.html` and a GitHub Pages workflow. In repository Settings → Pages, choose **GitHub Actions** as the build and deployment source.
