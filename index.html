Install it

STEP 01

Download the pack

Click the download button to save the .mcpack file.

STEP 02

Import into Minecraft

Open the file with Minecraft if your launcher supports file imports. Otherwise import it through Minecraft's behavior-pack workflow.

STEP 03

Enable the behavior pack

Open your world's settings, go to Behavior Packs, activate Cobblestone V Dripstone, then load the world.
